# 👋 Hola, soy Francisco Pérez

### Desarrollador Full Stack | Especialista en Backend
*Construyo cimientos de software robustos y escalables para que las ideas puedan crecer sin límites.*

<br>

Soy un Ingeniero de Software apasionado por la arquitectura y la resolución de problemas complejos. Aunque hoy mi mundo gira en torno a **Node.js** y **TypeScript**, mi viaje en la tecnología es una historia de resiliencia: pasé de ver la programación como un muro insuperable a descubrirla como mi "LEGO digital".

Esta mentalidad de "construir con bloques" define cómo trabajo. Me permite diseñar sistemas que no solo funcionan, sino que son mantenibles, escalables y están preparados para el futuro. Disfruto enfrentando desafíos técnicos, desde optimizar una consulta en **SQL** hasta implementar una arquitectura **multi-tenant** desde cero.

Actualmente busco un rol remoto como **Desarrollador Backend** o **Full Stack**, donde pueda aportar mi visión de ingeniería y mi diversa experiencia técnica para construir productos de alta calidad.

As a kid I asked for a LEGO set every single year. It never came. Years later, in a technical high-school classroom, programming clicked overnight — and code became my LEGO: I solve problems by assembling blocks in my head, a piece at the top, a piece at the bottom, until everything snaps together. Over a decade later, that's still how I build: **ERPs, POS platforms and multi-tenant SaaS running in production**, from a trucking company's payroll engine to workshop-management systems for franchising auto shops.

I don't collect certificates of things I've read — I ship systems, then go back and make them better. Every repo below is evidence.
